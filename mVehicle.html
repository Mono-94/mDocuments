Features​

  • Fully compatible with ESX, QBOX OX (WIP) and standalone (requires database)
  • Vehicle are persistent
  • Ability to add metadata to vehicles
  • Records total kilometers driven by vehicles
  • Prsonal vehicle menu
  • Key system | item/database.
  • Engine ignition | item key/database
  • Menu for sharing keys
  • FakePlate sistem
  • LockPick | Hotwire , Adapt your skillscheck and dispatch via Config.LockPickItem | Config.HotWireItem
  • Seat Shuffle | Anti Seat | Shuffle + Shift + E to shuffle seat*
  • Enter near vehicle door
  • Engine sound sync
  • Simple set vehicle density and close all NPC vehicles
  • Deactivate helmet on bike (optional)
  • Radio Vehicle | Install via item, save Vehicle PlayList ( xSound - Dependency )

Dependencies​

  • OneSync
  • OXMYSQL
  • ox_lib
  • ox_inventory (only keys as item)
  • ox_target (Trailer manager)
  • Recommended latest FiveM GameBuild
  • Recommended latest Artifacts
